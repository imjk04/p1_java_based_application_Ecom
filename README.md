# p1_java_based_application_Ecom
Automation Deployment using Jenkins (Freestyle & Pipeline Jobs)
Tech Stack: Git, GitHub, Jenkins, Maven, Nexus, Apache Tomcat
Designed and implemented CI/CD pipelines using Jenkins Freestyle and Declarative Pipeline jobs, integrated with GitHub for source code management and Maven for application builds.
Configured Nexus Repository Manager to store build artifacts and automated application deployment to the application server.
Implemented the Jenkins Controller-Agent architecture to execute pipeline jobs and build, deploy, and run applications on the same server.
Maintained Jenkins and Nexus servers to ensure smooth pipeline execution and artifact management.
